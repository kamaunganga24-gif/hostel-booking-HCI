 System Overview & 12 UI Screen Descriptions

1. **Screen 1 (Splash / Login ):** User login and registration landing screen.
2. **Screen 2 (Home / Search & Filter):** Main hostel discovery feed with price range, and  location.
3. **Screen 3 (Hostel Detail View):** Comprehensive hostel information, room types, photo gallery, and reviews.
4. **Screen 4 (Room Selection):** Interactive layout for selecting single vs. shared rooms with real-time pricing.
5. **Screen 5 (Side-by-Side Comparison):** Direct comparative matrix for contrasting amenities, pricing, and distances.
6. **Screen 6 ( Booking/Application Form):** Progressive wizard for entering personal information 
7. **Screen 7 (Document Upload):** Uploading the student ID for identity verification.
8. **Screen 8 (Booking Review):** Review of a stundents application form before submission.
9. **Screen 9 ( Success Confirmation):** Confirmation of application acceptance.
10. **Screen 10 (Payment Portal):** Student can pay for the accommodation, payment methods stated.
11. **Screen 11 (Payment receipt):** Receipt veiwing and download after payment.
12. **Screen 12 (Student Dashboard):**  Application status tracker showing "Pending Deposit" and students details.



 Usability Testing Summary (V1 vs. V2 Iterations)

| Identified V1 Issue | User Impact | V2 Design Fix Applied |
| :--- | :--- | :--- |
| **Cluttered Application Form** | Users felt overwhelmed by 14 consecutive fields | Converted into a 2-Step Wizard format |
| **Silent Payment Redirection** | Users were unsure if payment went through | Added an explicit modal popup with receipt download |
| **Small Navigation Buttons** | Users struggled to return to search results | Standardized persistent top-left back buttons |
